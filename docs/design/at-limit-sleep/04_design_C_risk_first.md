# Sleeping clusters at their sds caps — design

Repository: `<repository>` (files `dolle_sim/engine.py`, `dolle_sim/statics.py`, `dolle_sim/loads.py`, `dolle_sim/dem.py`, `dolle_sim/verify_full.py`). Nothing was edited; no simulation was run.

## 0. Why the static clusters are refused today (read from the code)

1. **Entry vs stay margins.** `_try_sleep_island` (engine.py ~1930) requires `rr.max() <= 1 - 5*margin` = 0.90 at T and T+H, while the stay test (`_step_once` ~495, `_skip_asleep` ~1170) only needs 0.98. The microgravity edge grain (twist 0.962/0.956) and the 3-grain bridge (roll 0.926) fail only this hysteresis.
2. **Residual-motion test is relative to the remaining margin.** `sqrt(2 kmax (Ek+Ep)) <= 0.01 * mf` with `mf = (1-rr)*mu*Fncrit`: at a contact sitting at its cap (rr = 1 - 1e-8, see 1.1) `mf = 0`, so no cluster at a cap can ever pass, however still it is. The same `0.01*(1-rr)` appears in the energy-ellipsoid branch and `_linres`.
3. **The tangent is kinked at a cap.** `statics._jac_coo` takes central differences with `EPS_X = 1e-13 m`. A contact clipped in the last DEM step sits at `|f_r| = F_cap - g_r|v_l|` i.e. within ~1e-8 F_cap (≈ 5e-16 m in ξ) of the kink, far inside EPS_X. So K and J at a capped contact are the average of the elastic and the released slope: neither the elastic response nor a bound.
4. **No between-sample bound.** The stay test samples T, T+H/2, T+H and relies on the 2% margin to cover what happens in between. At zero margin that is not a certificate.
5. **Latent twist-reset hazard.** `dem.contact_force` twisting branch: at `mt == 0` exactly, an over-cap twisting spring gets `sg = 0` → `h[H_XTW] = 0`, `tq = 0` (LAMMPS gran_sub_mod_twisting SDS does the same; the kernel must stay as it is, it is the verified reference). `statics._eval` with `dU = 0` (used by `statics.state`) and `_advance` with a zero rotation increment, and the first `compute_forces` in `_dem` after a wake (v = w = 0), all evaluate at exactly zero twist rate. A twisting spring left at `|K_tw ξ_tw| >= M_cap` by rounding is then silently reset to zero: a change of the plastic state by the whole cap. Today it is latent only because capped clusters never sleep.

## 1. Physics at a cap and the failure modes

### 1.1 Numbers (silica 50 µm on borosilicate, from `make_params`, the LAMMPS check and checks 3/8)
F_c = 1.06e-5 N, 2F_c = 2.1e-5 N; m = 1.15e-9 kg; a0 ≈ 0.37 µm; ξ_crit = h a0/12 = 15.6 nm; k_r = 4F_c/R = 0.85 N/m; rolling cap at zero load F_r,cap = μ_r·2F_c = k_r ξ_crit = 1.3e-8 N (1.2 g·m; check 3: 1.29 g); k_n = 1.2E*a0 ≈ 1.5e4 N/m; k_s ≈ 4e4 N/m; K_tw ≈ 8e-9 N·m/rad, M_cap ≈ 1.6e-10 N·m (cap angle 0.02 rad); rocking ω_r ≈ 2.3e4 rad/s, Q = 100 → g_r ≈ 3.7e-7 N·s/m, G_tw ≈ 1e-15 N·m·s. **Fncrit = |Fne + 2F_pull| is dominated by 2F_c: the whole 25 g pressing load changes it by m·245/2.1e-5 = 1.3%; the coast's drag decay (≈1-2 g → 0.2 g, T+29.1-54 s) by 0.5-1e-3.** Sliding caps (0.4·Fncrit ≈ 730 g·m) are never approached in flight; pull-off is a break, not a cap.

### 1.2 What the kernel does at a cap with zero relative motion
Rolling (dem.py ~340-360): `xr += vl dt`; `fr = -kr xr - gr vl`; if `|fr| > Frcrit`: `xr = -(s fr + gr vl)/kr`, `fr *= s`. With `vl = 0` and a constant cap: no change. With a shrinking cap (Fne dropping): clipped by exactly the cap change (radial return, direction kept). With an elastic demand increase (`|fr_el| > Frcrit`): clipped; the force deficit is carried by the rest of the structure → the cluster creeps. Perpendicular perturbations are elastic to first order (the sphere constraint is second order). Same for sliding (3-vector) and twisting (scalar). So a capped sds spring is a *one-sided* (elastic-perfectly-plastic) hinge in the radial direction and elastic otherwise: the static problem is a complementarity problem, not a linear one.

Where the measured clusters live: second burn T+17.4-29.1 s: axial 25 g constant, spin rising linearly 2.9 → 4.8 Hz → centripetal demand rising ≈ 2.8e-3 F_r,cap per 4 ms step → the capped rolling contacts of a pile must flow (genuine quasi-static creep; that is what the DEM is computing at 1e8 steps/s). Coast T+29.1-54 s: spin constant, pressing load decaying → demand constant, caps shrink by ≤ 1e-3 in total; load redistribution inside piles of order the drag change (≈ 2e-4 F_r,cap per step at worst). Microgravity: loads 1e-4 g = 1e-4 F_r,cap in total, nearly constant.

## 2. Statics upgrades (`dolle_sim/statics.py`, `dolle_sim/loads.py`) — used by both tiers

2.1 `lift_caps(prm) -> prm_el`: copy with `P_MUT = P_MUR = P_MUTW = 1e300`. Every tangent/evaluation (`jacobians`, `state`, the sample evaluations of 2.4) uses `prm_el`: the kernel never clips, so central differences never straddle a kink (**K_el, J_el are the exact elastic tangents at the current state**) and the twist branch never resets. `apply_displacement` with the *real* `prm` is used only where a state is handed to the DEM (entry placement, wake, Tier 2 step), so the kernel's own clipping is the return map.

2.2 `row_norms(lu, J) -> rn[8nc]`: ‖K_el⁻ᵀ J_cᵀ‖₂ per contact component (block solves `lu.solve(Jt_block, trans='T')`, as `energy_bounds` does). Stored in the island.

2.3 `Loads.accel_curv_bound(T0, T1)` (loads.py): per-axis bound on |a''| over the step: the same construction as `accel_bound` (5 profile samples + knots; second differences, doubled, plus a factor 2 at zero margin = ×4 total), exact zero on the constant/piecewise-linear pieces, exact ω² A on half-sine pieces; spin part: |cen''| ≤ 2|Ω̇|²r_max (Ω linear between knots, knots are breakpoints), Euler 0. Engine side `_island_curv(mem, T0, T1)`: the generalised-force vector F''_bound (m_g × a''_bound per grain translation, 0 rotation) → scalar ‖F''‖₂. Between two samples a distance h apart: |λ_c(t) − interp| ≤ (h²/8) rn_c ‖F''‖₂ (Cauchy-Schwarz on the row of J K⁻¹; λ is linear in F). The ratio of a convex norm to an affine positive Fncrit along a segment is ≤ the larger endpoint value (mediant inequality), so evaluating `margins_bounded(λ_sample, dlam)` at each sample with `dlam = (h²/8) rn ‖F''‖₂ + nl` bounds the whole step. `nl` = measured |λ_kernel − λ_linear| at the samples (2.4), added as a safety term.

2.4 `equilibrium(x, ci, cj, prm_eval, hist, L, lu, J, Fext, du0, tol) -> (du, xn, hn, lam, out, r, nit)`: Newton with the kernel as the residual: `xn, hn = apply_displacement(x, …, hist, du)` (fresh copy from the reference every iteration), `lam, Fnet, out = state(xn, …, hn)`, `r = Fext + Fnet`; stop when `|J K_el⁻¹ r|∞ ≤ tol`, else `du += lu.solve(r)`; ≤ 4 iterations (quadratic for elastic states). Returns `broke = (out[:,10] < 0.5).any()`.

2.5 `guard_twist(prm, hist, Fne, rel=1e-12)`: for each contact with `|K_tw ξ_tw| ≥ (1-rel) μ_tw |Fne + 2F_pull|`, set `ξ_tw = sign · (1-rel) M_cap/K_tw`. Documented change ≤ 1e-12 M_cap ≈ 1.6e-22 N·m (the DEM's own clip at residual rates moves it by G_tw·ṁ ≈ 1e-24-1e-22 N·m). Called after every `apply_displacement` with real `prm` whose result is written to `self._hist`.

2.6 `near_cap(lam, prm, out, thresh) -> (idx_comp, dirs, kcomp)`: components with ratio > thresh (sliding 3-vector, rolling 3-vector, twist scalar), their unit radial direction λ̂ and spring constant (k_s a0 or Mindlin k_s a, k_r, K_tw).

2.7 `release_norm(lu, J, near) -> ‖B_m‖₂`: m×m matrix `B_ab = λ̂_aᵀ J_a K_el⁻¹ J_bᵀ λ̂_b / sqrt(k_a k_b)` (Sherman-Morrison-Woodbury for releasing the m radial directions: released compliance = (I − B_m)⁻¹ × elastic). The amplification of any hinge flow is ≤ 1/(1 − ‖B_m‖₂).

2.8 (Tier 2) `plastic_step(...)`: see §4.

## 3. Tier 1 — sleep at the cap with an exact certificate and a budgeted flow bound

Config (`cfg["contact"]`): `cap_sleep` (True), `cap_budget_step` B_STEP = 2e-4, `cap_budget_total` B_TOTAL = 2e-3 (fractions of the cap force), `cap_beta_max` β_max = 0.75, `cap_tol_r` = 0.1·B_STEP (fraction of the smallest cap), hysteresis `cap_hyst_steps` = 20; `sleep_margin` keeps its role for pull-off and single-wall grains.

### 3.1 Entry — `_try_sleep_island(mem, touch, T, H)` (replaces the body from `K, J = statics.jacobians(...)` on)
1. As now: no fast window / breakpoint in [T, T+H]; `ci, cj, rows`; `prm_el = lift_caps(prm)`; `K_el, J_el = jacobians(x, …, prm_el, hist)`, `lu = splu(K_el)` (refuse if singular).
2. Equilibrium at F(T): `lam0, Fnet0, out0 = state(x, …, prm_el, hist)`; `du0 = lu.solve(Fext + Fnet0)`; `equilibrium(..., prm (REAL), ...)` → the kernel places the cluster, clipping as the DEM would settle it; refuse `cluster_awake_nonlinear` if not converged (a cluster still flowing). `guard_twist`. Write `x, hist` back; `v = w = 0`.
3. Reference at the placed state: `K_el, J_el, lu` recomputed; `lam, Fnet, out = state(xn, …, prm_el, hn)`; `F_ref = _island_load(mem, T)`; `rn = row_norms(lu, J_el)`; ratios `ρ = margins(lam, prm, out)`.
4. Pull-off and yield: `r_pull ≤ 1 − margin` everywhere (and at T+H via the linear prediction), predicted overlap ≤ `P_DY`; else refuse.
5. Near-cap set N = components with ρ > 1 − margin (0.98). If N ≠ ∅: `release_norm ≤ β_max` else refuse `cluster_awake_beta` (near-mechanism: the DEM is the right tool).
6. Residual motion (ratchet bound, replaces `0.01*mf`): `E = Ek + 0.5 du0ᵀ K_el du0` (K_el ≥ K_true as a quadratic form, so E is an upper bound on the available energy). For every component in N: `E/F_cap,c + g_c sqrt(2E/m_min)/k_c ≤ 0.1 B_STEP ξ_cap,c` (plastic work ≤ E; dashpot share of the last clip). For components not in N: the existing `energy_bounds` test but against the *cap* (`worst ≤ 1` with `dl`), not against `0.01(1−rr)`. If the elastic part fails → `_linres` (3.4); if the ratchet part fails → refuse `cluster_awake_ratchet` (never linres a capped contact).
7. Stay certificate for the first step with hysteresis: `_island_check(isl, T, T+H)` must pass with excess_step ≤ B_STEP/2 and, extrapolated linearly over `cap_hyst_steps` steps, ρ_pred ≤ 1 for non-near components and Σ excess ≤ B_TOTAL (a sleep must be worth ≥ 20 steps).
8. Store the island (fields in §5), `regime = ASLEEP`, counters.

### 3.2 Stay — `_island_check(isl, T0, T1) -> (ok, why, excess_step)`, called from `_step_once` (per island, replacing the `_island_ratio` loop) and `_skip_asleep` (per dt_s interval)
1. Samples Ts = T0, (T0+T1)/2, T1 (h = (T1−T0)/2). For each: `ΔF = _island_load(mem, Ts) − F_ref`; `du = lu.solve(ΔF)`; `lam_lin = lam + J_el du`; exact elastic evaluation `equilibrium(prm_el, du0 = du, tol = cap_tol_r)` on copies (one Newton step suffices); `broke` → wake `predicted_break`; `nl_c = |lam_k − lam_lin|`.
2. `dlam = (h²/8) rn ‖F''‖₂ + max_s nl` (component-wise); `worst_s = margins_bounded(lam_s, dlam, prm, out_s)`.
3. Pull-off: `max_s r_pull ≤ 1 − margin`, else wake `pulloff`.
4. For every other component: `excess_c = max_s (worst_s,c − 1)⁺`. Require `max_c excess_c ≤ B_STEP` (else wake `excess`) and `budget + max_c excess_c ≤ B_TOTAL` (else wake `budget`). Components not in N with `worst ≤ 1` are exact elastic; the 0.98 is no longer a stay requirement for them (the certificate is rigorous, the margin was covering R1).
5. Return `excess_step = max_c excess_c`; the caller stores it in `self._chk["island_budget"][iid]`; `step()` commits `budget += excess_step` after the step is accepted (redo-safe: island dicts are never mutated inside `_step_once`; `_snapshot` is shallow). `_skip_asleep` commits directly (it is never redone).

### 3.3 Wake — `_wake_island(iid, T)`
1. `du = lu.solve(F(T) − F_ref)` (+ the linres residual as now); `equilibrium(prm REAL, du0 = du)` from the reference: the kernel's clipping applies the budgeted return map, Newton with K_el removes the deficit (converges because β ≤ β_max); `guard_twist`; write back; `v, w` = 0 or the residual.
2. Report: `n_events["cap_budget_spent_max/sum"]`, `cap_flow_bound_max_xi = budget/(1−β)` (in units of ξ_cap), `wake_reason_*` counters, and after the step `wake_transient_max_m = max chk["dmax"][members]` (the DEM's own measure of how far the woken grains moved in the wake step — the a-posteriori check that the deficit relaxation was small).
3. Other wake causes unchanged: fast window / breakpoint (`fast`), `_watch` (a DEM grain within 2 d_cap), forced by a redo.

### 3.4 `_linres` with caps
Use `K_el, J_el` and `C, J_v` from `jacobians(vel=True, prm_el)`. Require `margins_bounded(lam_eq/lam_end, dl) ≤ 1` for all components (not `1 − 5 margin`) and, for components in N, `dl_c ≤ 0.1 B_STEP F_cap,c` (a tracked linear residual at a capped contact would ratchet nonlinearly — refuse rather than track). `_island_check` keeps using `dl` through `margins_bounded` as now.

### 3.5 Single grains on one wall (`_try_sleep`, `_margins`, `_classify`)
A single contact is isostatic: the demand equals the load, so a grain above its cap rolls (mechanism) and belongs to ROLL; no cap sleeping there. Changes: entry margin = stay margin (≤ 1 − margin) with the 20-step hysteresis on the predicted drift; `_margins` gets the between-sample term `dlam = m (h²/8) a''_bound` (direct: λ is the load). This covers single-wall grains at 0.90-0.98 in microgravity.

### 3.6 The bound (Tier 1), derivation and size
Setting: hinge DOF ξ at contact c, spring k_c (capped at F_cap), the rest of the structure seen from the hinge as k_rest in parallel, demand D. Elastic: f_el = k_c D/(k_c + k_rest). If f_el = F_cap + e (excess e), the real state has the spring at F_cap and the plastic history change (what the DEM's clipping accumulates) is Δξ_p = e (1/k_c + 1/k_rest) = (e/k_c)(1 + k_c/k_rest) = (e/k_c)/(1−β), β = k_c/(k_c + k_rest) = the diagonal of B_m; the grains move beyond the elastic prediction by e/k_rest = (e/k_c) β/(1−β). With m hinges released simultaneously the same holds with 1/(1−‖B_m‖₂). Hence, over a sleep interval in which the certified excess never exceeded B (relative to the cap) and ‖B_m‖₂ ≤ β_max:
* plastic history change at any contact ≤ **B ξ_cap/(1−β_max) = 4 B ξ_cap**; with B_TOTAL = 2e-3: **≤ 8e-3 ξ_cap = 0.12 nm** (silica 50 µm); for a corner grain β ≈ k_r/k_n ≈ 6e-5 and the factor is 1;
* force deficit at wake ≤ B F_cap = 2.6e-11 N (2e-3 g on the grain), removed by the kernel's return map + Newton before the DEM sees the state; grain displacement beyond the frozen position ≤ 4 B F_cap |K_el⁻¹ J_cᵀ λ̂_c| (computable from the same solves; ≈ 4 B ξ_cap when the alternative path is another rolling spring, ≈ B ξ_cap k_r/k_n for a corner);
* ratchet (R2): ≤ E/F_cap + g_r√(2E/m)/k_r ≤ 0.1 B_STEP ξ_cap by construction; for the measured speeds (≤ 2e-9 m/s, E ≲ 3e-27 J) it is ≤ 1e-19 m;
* between samples (R1): (h²/8) rn ‖F''‖₂ with h = 2 ms: drag decay (τ ≳ 5 s) ≲ 1e-5 F_r,cap; the spin-up (Ω̇ ≈ 1 rad/s², r ≈ 0.15 m) 2Ω̇²r m h²/8 ≈ 3e-16 N ≈ 2e-8 F_r,cap; chute/splash half-sines ≈ 1e-2 F_r,cap → the island wakes there, correctly;
* linearisation (R9): zero at the samples (exact kernel + Newton to `cap_tol_r` = 2e-5 of the cap); second order between samples, covered by `nl` in `dlam`;
* twist guard (R4): ≤ 1e-12 M_cap per apply;
* when B = 0 over the whole sleep (microgravity: ΔF ≈ 1e-4 F_cap in total) the treatment is exact: no plastic variable changes and the elastic response is the kernel's to `cap_tol_r`.
All of these are accumulated per island and reported in `n_events` (→ `timeseries`, mission summary).

## 4. Tier 2 — quasi-static plastic stay step (flag `plastic_sleep`, default off until V4 passes)

Needed for piles whose capped contacts are *loaded further* each step (the burns with rising spin; load redistribution in the 12- and 57-grain piles): there the DEM does genuine quasi-static creep and Tier 1 correctly refuses. The island then advances quasi-statically instead of waking:

`_island_plastic_step(isl, T, H)` (called in `_step_once` when `_island_check` fails only by `excess`/`budget`):
1. Predictor: `du = lu.solve(F(T+H) − F_ref)`; `xn, hn = apply_displacement(x_ref, …, prm REAL, hist_ref, du)` (the kernel clips = return map); `lam, Fnet, out = state(xn, prm_el, hn)`; `r = F(T+H) + Fnet`.
2. Active set A = components the kernel clipped (|λ| = cap); consistent tangent `K_A = K_el − Σ_{c∈A} (1/k_c)(λ̂_cᵀ J_c)ᵀ(λ̂_cᵀ J_c)` solved by Woodbury on the cached `lu`; `du += K_A⁻¹ r`; re-apply from the reference; repeat until `|J K_el⁻¹ r|∞ ≤ cap_tol_r` and A is stable (≤ 8 iterations; else wake `plastic_newton`).
3. Bounds (explicit, accumulated, reported): (a) dynamic terms neglected: `f_dyn = M (du−du_prev)/H² + (C + G) du/H` → `|J K_el⁻¹ f_dyn|∞ ≤ 0.1 B_STEP cap_min` else wake (`plastic_dyn`); for the coast (v ≈ 1e-9 m/s) this is ≈ 1e-6 of the cap; (b) path error: redo the step as two half-steps (loads at T+H/2) and take `2 × |hist_plastic(1 step) − hist_plastic(2 half-steps)|∞` as the bound on the return-map discretisation error (first-order method); require ≤ 0.1 B_STEP ξ_cap per step (else sub-step ×4, then wake); (c) |du|∞ ≤ 0.1 d_cap per step and Σ|du| over the sleep ≤ 0.1 d_cap (`creep_budget_m`; no new contact can form, `_watch`'s 2 d_cap rule holds); (d) pull-off/break/yield as in 3.2.
4. Commit by *replacing* the island dict: `x_ref, hist_ref` written to `self.x[mem], self._hist[rows]` (so `_restore` undoes them on a redo), `lam, out, F_ref, T_ref` re-based; `K_el, J_el, lu, rn` recomputed only when a component clipped or Σ|du| since the last tangent > 1e-3 a0 (the tangent changes by du/a0 ≈ 3e-5 per elastic step).
5. `_step_once`: `s[mem] = |du|` (not 0) so capture times and `_verify` see the motion; `guard_twist` after each commit.
Cost per outer step: 3-6 kernel passes over the island's contacts + sparse solves ≈ 1-5 ms for 57 grains (vs 4e5 DEM steps × 57 grains now).

## 5. Code changes by function

`dolle_sim/statics.py`: new `lift_caps`, `row_norms`, `equilibrium`, `guard_twist`, `near_cap`, `release_norm`, (Tier 2) `plastic_step`, `woodbury_solve`; `state` returns `out` as now (callers read `out[:,10]`); `margins_bounded` unchanged; module docstring: "every tangent is taken with the caps lifted".

`dolle_sim/loads.py`: `accel_curv_bound(T0, T1)`; `spin_curv_bound(T0, T1) = 2|Ω̇|² r_max`.

`dolle_sim/engine.py`:
* `__init__`: knobs above; `n_events` keys `cap_*`, `wake_reason_*`, `wake_transient_max_m`, `twist_guard_applied`, `plastic_*`.
* `_island_curv(mem, T0, T1)`, `_island_predict(isl, Ts)` (replaces `_island_ratio`; keeps the `dl` path), `_island_check(isl, T0, T1)`, `_island_upgrade(isl)` (lazy defaults for islands from old checkpoints: `prm_el`, `rn`, `near`, `budget = 0`, `beta`), `_island_plastic_step` (Tier 2).
* `_step_once` ~495-505: the island loop becomes `ok, why, ex = self._island_check(isl, T, T+H)`; `self._chk["island_budget"][iid] = ex`; wake with `wake_reason_<why>`; Tier 2 branch; `s[mem] = |du|` for plastic islands.

## 7. Expected speed-up and risks

Measured now: silica tubules 6000-10000 s CPU per flight-second in the coasts; microgravity would cost days per tubule; 4e7-1.2e8 DEM steps per flight-second.
* Microgravity (T+88-313 s and the rest of the flight): the edge grain and the bridge pass the relaxed entry (no cap involved: 0.926-0.962 ≤ 0.98 with the hysteresis) and, with everything asleep, `_skip_asleep` skips 2 s per call; ≈ 3000 kernel passes on ~5 contacts per skip → the phase costs seconds. Days → minutes (≥ 1e3×).
* Coast T+29.1-54 s (constant spin, decaying drag): corner/edge grains and the 2-5 grain clusters sleep with ≤ 1 budget wake (cap shrink ≤ 1e-3 total vs B_TOTAL 2e-3); the 12- and 57-grain piles sleep while the redistribution excess per step ≤ B_STEP (unknown fraction f of the time; the worst-case per-step excess ≈ 2e-4 F_cap is at the threshold). If the piles sleep, the coast drops to the rollers only (≈ 50× or more); if not, Tier 1 saves only the small clusters (≈ 1.3-3×) and Tier 2 is required.
* Burns (rising spin, T+0-5.2 and 17.4-29.1 s): capped contacts load up by ≈ 2.8e-3 F_cap per step: Tier 1 refuses (correctly); Tier 2 advances them at ≈ 1-5 ms per outer step → ≈ 1 s CPU per flight-second for a 57-grain pile (≈ 1e3-1e4× for those grains).
Risks: (1) the piles may need Tier 2 for most of the coast too (f small) — measure `wake_reason_excess` on the autosaves first; (2) `_skip_asleep`/`_step_once` cost grows with 3 kernel passes per island per step (fine for ≤ 100 contacts; for `max_island = 800` cap the exact-evaluation path at 128 grains and fall back to the linear prediction + nl = 0 with the old 0.98 stay); (3) the inherited curvature heuristic (R13) — V3 quantifies it; (4) Newton at wake fails to converge for β near β_max (fall back: hand the last iterate to the DEM, report the residual); (5) chatter if B_STEP is too small — the 20-step hysteresis bounds the cost to ≤ 5% of the DEM time; (6) the campaign cannot continue bit-for-bit across the code change; (7) graphite: same formulas, F_c 1.8e-5 N, caps 1.7× larger — budgets are relative so unchanged.

## Entry criterion (summary)

Replace `rr.max() <= 1 - 5*margin` by: (1) elastic tangents K_el, J_el from the kernel with caps lifted (prm copy with mu_t, mu_r, mu_tw = 1e300), equilibrium at F(T) solved by Newton with the kernel itself as the residual (real prm, so the kernel settles the cluster; refuse if it keeps clipping) and |J K_el^-1 r| <= 0.1*B_STEP*cap_min; twist guard applied. (2) Pull-off ratio <= 1 - margin at T and T+H and predicted overlap <= delta_y; no predicted break. (3) Near-cap set N = components with ratio > 1 - margin (0.98); if N non-empty the released-compliance norm ||B_m||_2 (m x m Schur block of J K_el^-1 J^T scaled by 1/sqrt(k_a k_b)) <= beta_max = 0.75, else refuse (near-mechanism). (4) Residual motion E = Ek + du^T K_el du/2: for every component in N, E/F_cap + g_c*sqrt(2E/m)/k_c <= 0.1*B_STEP*xi_cap (plastic work <= residual energy: ratchet bound); for the others the energy-ellipsoid bound must keep them <= 1 (cap), with _linres allowed only when no component of N is involved. (5) The stay certificate `_island_check(isl, T, T+H)` (3 samples evaluated exactly by the kernel + between-sample curvature bound) passes with excess_step <= B_STEP/2 and, extrapolated 20 steps at the current drift, rho <= 1 for non-near components and the summed excess <= B_TOTAL (anti-chatter hysteresis). Single-wall grains: entry = stay (<= 1 - margin with the curvature term) + the same 20-step hysteresis; no cap sleeping (isostatic: above the cap they roll).

## Stay and wake (summary)

Stay (every outer step in _step_once and every dt_s interval in _skip_asleep): `_island_check(isl, T0, T1)`: at Ts = T0, mid, T1 compute du = K_el^-1 (F(Ts) - F_ref), evaluate the predicted elastic state exactly with the cap-lifted kernel plus one Newton step (copies), lam_s; between-sample bound dlam = (h^2/8) * ||K_el^-T J_c^T||_2 * ||F''||_2 + measured |lam_kernel - lam_linear|, with ||F''|| from Loads.accel_curv_bound (profile curvature, 2|Omega_dot|^2 r_max for spin); worst_s = statics.margins_bounded(lam_s, dlam) (normal lowered, so the cap Fncrit is at its worst). Wake if: any pull-off ratio > 1 - margin or a predicted break; any component's excess (worst - 1)+ > B_STEP = 2e-4; budget + excess > B_TOTAL = 2e-3; a fast window or breakpoint in the step; a DEM grain within 2 d_cap (_watch); forced by a redo. Otherwise the island stays frozen and the step's excess is committed to its budget in step() after acceptance (redo-safe; _skip_asleep commits directly). Wake (_wake_island): du = K_el^-1 (F(T) - F_ref) (+ the linres residual), kernel apply with the real prm (its clipping is the return map of the budgeted flow), Newton with K_el until |J K_el^-1 r| <= tol, twist guard, v = w = 0; report budget spent, 4*budget*xi_cap as the flow bound, the wake reason, and after the step the DEM-measured transient max chk["dmax"][members]. Tier 2 (flag plastic_sleep): when the only failure is excess/budget, advance the island quasi-statically with the kernel return map and an active-set Newton (Woodbury on K_el), re-base the reference, set s[members] = |du|, and wake instead if the dynamic-term bound, the half-step path error, |du| > 0.1 d_cap, or the summed creep > 0.1 d_cap is exceeded.

## What is exact and what is bounded (summary)

Tier 1. Exact when the accumulated excess B is 0 (no plastic variable changes; the elastic response is the kernel's own to tol = 0.1*B_STEP of the cap at the samples). Otherwise, with a hinge of spring k_c at its cap and the rest of the structure k_rest, an elastic excess e gives a plastic history change e(1/k_c + 1/k_rest) = (e/k_c)/(1 - beta), beta = k_c/(k_c + k_rest) = diagonal of B_m, and a grain displacement beyond the frozen position of (e/k_c)*beta/(1-beta) times |K_el^-1 J_c^T lambda_hat|; with m hinges the factor is 1/(1 - ||B_m||_2). Hence: plastic history change <= B*xi_cap/(1 - beta_max) = 4*B*xi_cap <= 8e-3 xi_cap = 0.12 nm (silica 50 um, B_TOTAL = 2e-3, xi_cap = 15.6 nm; corner grain beta ~ 6e-5 so factor 1); force deficit at wake <= B*F_cap = 2.6e-11 N (2e-3 g on the grain), removed by the kernel's return map + Newton before the DEM sees the state; ratchet from the dropped residual <= E/F_cap + g_r sqrt(2E/m)/k_r <= 0.1*B_STEP*xi_cap by construction (<= 1e-19 m for the measured speeds <= 2e-9 m/s); between samples (h = 2 ms) (h^2/8)||K^-T J_c^T|| ||F''|| <~ 1e-5 F_cap in the coast drag decay, 2e-8 during spin-up, ~1e-2 in chute/splash half-sines (wake there); linearisation zero at the samples, second order between them and included via the measured |lam_kernel - lam_linear|; twist guard <= 1e-12 M_cap per apply. All accumulated per island and reported (cap_budget_spent_*, cap_flow_bound_max_xi, wake_transient_max_m). Tier 2: the state after each step is a kernel state in equilibrium to tol; neglected dynamics |J K_el^-1 (M a + (C+G) v)| <= 0.1*B_STEP*cap (about 1e-6 of the cap at 1e-9 m/s); return-map path error bounded by 2x the one-step vs two-half-step difference, <= 0.1*B_STEP*xi_cap per step, accumulated and reported.

## Risks stated

- The 12- and 57-grain piles may exceed B_STEP most of the coast (load redistribution ~2e-4 F_cap per step is at the threshold): Tier 1 alone then saves only the small clusters (1.3-3x) and Tier 2 is required for the full coast speed-up; the burns (rising spin) need Tier 2 in any case.
- The load-curvature bound inherits accel_bound's heuristic (doubled second differences) for the smooth ascent drag; it is exact only for constant, piecewise-linear and half-sine pieces. V3 measures it; a profile-derived analytic bound would close it.
- Newton at wake may stall when ||B_m|| is near beta_max (contraction ~beta per iteration); fallback hands the last iterate to the DEM and reports the residual, so the wake transient is measured rather than bounded in that case.
- Per-step cost grows by ~3 kernel passes per island (exact sample evaluation); fine to ~100 contacts; islands above ~128 grains need the linear-only fallback with the old 0.98 stay, or a capped dense row-norm computation.
- Chatter if B_STEP is too small for a phase: bounded by the 20-step hysteresis to <= 5% of the DEM time, but still a cost; the knobs are config-exposed and must be re-verified if changed (V1/V4 report the slept fraction).
- The shallow _snapshot shares island dicts: any in-place mutation (budget, re-basing) would survive a redo; the design forbids in-place mutation and commits in step(), which must be enforced in review and by the redo unit test.
- A campaign continued from an autosave across the code change is no longer bit-for-bit the uninterrupted old run; results are still verified but the bit-for-bit statement in the README must be scoped to one code version.
- The twist-reset quirk is a property of the verified kernel (and of LAMMPS); the guard only avoids triggering it from the engine's zero-rate evaluations; a capped twist can still hit it inside the DEM if a grain's spin component along n is exactly zero at an evaluation (measure-zero, but worth a counter).
- Tier 2's path-error bound (2x the half-step difference) assumes first-order convergence of the return map; non-proportional loading with rotating cap directions is the case it is least tight for, which V4's spin-up load exercises.
