What runs here

The full simulator (dolle_sim) runs on Pyodide, which is CPython compiled to WebAssembly, with numpy and scipy. The physics is identical to the desktop version. Two speed settings differ: there is no numba JIT, and contacts are integrated with 100 instead of 300 sub-steps per impact, which changes outcomes by < 0.4%. Keep runs to a few hundred grains and a few seconds. For the full 2000-grain, 120 s flight, run it locally.

Reading the results

Truth is the sticking threshold from the exact 3D normal impact speeds of free single grains. Stereo is what two orthogonal cameras would measure, 1 camera what a single view would. Impacts onto grains stuck to a wall (twice the effective mass) are reported separately.

Runtime

Loading takes ~10–20 s the first time (cached afterwards). The default run (2 × 200 grains, 4 s) takes about a minute on a laptop. Time grows roughly with grains × seconds and with the number of wall impacts.

Save and share

Download config saves every setting as JSON. Upload it here again, or run it locally: python -m dolle_sim run my_config.json. Each result card has CSV downloads of every collision.
